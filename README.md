# Vampire Baby: Moonberry School Mayhem

GitHub-ready build. This folder contains only files actually used by the game; unused duplicate artwork and source sprite sheets were removed. Gameplay/code, music, original six playable characters, enemies, bosses, projectiles, NPCs, props, and level collectibles are unchanged.

Open `index.html` to play locally. For GitHub Pages, upload the CONTENTS of this folder so `index.html` is at the repository root.
